# 圣经释经资料检索台 · 网页版

本项目另行保留离线v1.6，不替换原离线包。网页版为按需加载的静态站点，无需用户安装Python或下载SQLite，无API Key。

实际正文135,983条：注释115,076条、讲章5,297篇、神学书籍段落15,610条。目录和检索索引单独加载，正文每300条一个压缩分片，仅打开结果时取对应片。多个正文关键词取交集，英语常用停用词不限制结果；不支持词根扩展和精确短语。中文匹配已译正文和中文作者别名，不翻译未译英文。

267条有中文，其余仍为原文；机器译文未校订。每条显示出处、版权与译文状态。OpenChristianData整理层按CC BY-NC4.0保守使用，保留CCEL来源署名；原著版权另列。旧版样本的版权待复核。

免费托管迁移：把dist目录作为静态发布目录，可迁移到EdgeOne Makers或Cloudflare Pages，分片均小于25MB。平台应直接提供.gz文件；程序也能处理已经被HTTP层解压的响应。需要现代浏览器支持DecompressionStream。

不包括在线机器翻译、定时采集或资料编辑后台。数据库与原始下载文件仍在离线备份。正文内容源自用户已有资料库，数量按独立文档计，不按经文关联重复计数。
